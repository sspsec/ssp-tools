## 人

### ✍️ 作家

- 东野圭吾 - 《白夜行》、《放学后》等，他的书我基本上都读过。
- 村上春树 - 《舞舞舞》、《刺杀骑士团长》，个人觉得魔幻主义多一点。
- 余华 - 《活着》、《许三观卖血记》，个人推荐《十个词汇里的中国》写的非常好。
- 莫言 - 《丰乳肥臀》、《檀香刑》，也有些超现实的描写，语言文字很美，很有画面感。
- 鲁迅 - 《呐喊》、《狂人日记》、《彷徨》，批判性极强。
- 梭罗 - 只看过《瓦尔登湖》这一本，对于梭罗在瓦尔登湖畔的独居生活很向往，文中对瓦尔登湖的描写很真实。
- 叔本华 - 《人生的智慧》，令我受益匪浅的一本书。

### 🎨 漫画家

- 押见修造 - 《血之辙》、《恶之华》、《欢迎回来爱丽丝》、《我在麻里体内》，他的作品基本上通读，无论从画工、剧情还是作品的内涵都是顶级。

- 桂正和 - 《I's》，《电影少女》，《I's》神作，男主心理描写细腻，看了一度有刚恋爱时的感觉~

- 冈田和人 - 《连裤袜》神作无需解释，《扭曲的同居生活》，有点擦边，基本上都是bad ending，看完心里难受很久。

- 藤本树 - 《电锯人》以及众多短篇漫画，画工，剧情没的说。

- 伊藤润二 - 《富江系列》、《旋涡》、《鱼》，每一部都是神作，他的作品我通读。

### 命令行工具 ⌨️

- [Homebrew](https://brew.sh/) - 用于安装各种软件的包管理器，macOS 必装。
- [Git](https://git-scm.com/) - 必备的版本控制工具，用来下载一些github上的项目。
- [Docker](https://www.docker.com/) - 开发和部署容器化应用的必备工具。
- [ImageMagick](https://imagemagick.org/) - 命令行图片处理工具，主要用于批量转换图片格式。
- [FFmpeg](https://ffmpeg.org/) - 命令行视频处理工具，适用于视频切片、转码等操作。
- [Ollama](https://ollama.com/) - 本地运行大语言模型的工具，性能要求较高。
- [sdkman](https://sdkman.io/) - 管理多种 SDK 版本的工具，我是用来管理本地的java环境，一键下载多个java环境。
- [pyenv](https://github.com/pyenv/pyenv) - Python 版本管理工具，用来管理本地的python环境，可以一键下载多个python环境。
- [gh](https://cli.github.com/) - GitHub 官方命令行工具，提 PR、查 issue、管理 release 很方便。
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) - 命令行视频下载工具，配合 FFmpeg 使用。

- [tmux](https://github.com/tmux/tmux) - 终端复用器，多窗口/会话保持必备。
- [bat](https://github.com/sharkdp/bat) - 带语法高亮的 cat 替代品。
- [uv](https://github.com/astral-sh/uv) - 极速 Python 包/版本管理，替代 pip + venv。
- [deno](https://deno.com/) - 现代化 JS/TS 运行时。
- [go](https://go.dev/) - Go 语言工具链，SSP 工具箱开发用。
- [maven](https://maven.apache.org/) - Java 项目构建工具。
- [node](https://nodejs.org/) - Node.js 运行时。
- [pandoc](https://pandoc.org/) - 万能文档格式转换（Markdown↔Word/PDF/HTML）。
- [tesseract](https://github.com/tesseract-ocr/tesseract) - OCR 文字识别。
- [exiftool](https://exiftool.org/) - 图片/文件元数据读写。
- [fastfetch](https://github.com/fastfetch-cli/fastfetch) - 终端系统信息展示（neofetch 替代）。
- [ranger](https://github.com/ranger/ranger) - 终端文件管理器，Vim 键位。
- [wget](https://www.gnu.org/software/wget/) - 命令行下载工具。
- p7zip / unar / rar - 各类压缩包解压命令。
- [you-get](https://github.com/soimort/you-get) - 视频下载工具。
